Explain **$ARGUMENTS** in **six sentences. Not five, not eight.**

Target: 30 seconds to read. Short enough that I never have to decide whether
to bother.

Six sentences is exactly enough to carry a real example, which is the whole
point of this length. Use them like this:

1. What it is.
2. How you actually do it.
3. **A concrete example with real numbers.**
4. The punchline of that example, the bit that makes it land.
5. Why this and not the obvious alternative.
6. What you actually get out of it.

Rules:

- No preamble. Start with the answer.
- Prose only. No bullets, no headings, no code block.
- Simple words, short sentences. English is not my first language.
- **Real numbers in the example.** Invented but specific beats vague.
- If this project has relevant data, use that instead of a made-up example.
- Judge my level from the question and pitch it there. If I asked what a loop
  is, I am a beginner. If I asked about attention masks, I am not.
- No em dash.
- Do not offer to explain more. If I want more I will type `/scroll`.

If six sentences genuinely cannot carry it, say so in one line and tell me to
use `/scroll`. Do not quietly write ten.
